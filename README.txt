# Agenda de Cultos — Versão 1

Aplicativo mobile em HTML + CSS + JavaScript.

## Como usar
1. Extraia a pasta.
2. Abra `index.html` no navegador do celular ou computador.
3. Use o botão `＋` para editar o culto e adicionar/remover itens.
4. Os dados ficam salvos no armazenamento local do navegador.
5. Use "Compartilhar" para enviar a programação; em celulares compatíveis será aberto o compartilhamento do aparelho. Em navegadores sem suporte, abre o WhatsApp.

## Arquivos
- index.html — interface
- style.css — visual responsivo
- app.js — cadastro, edição, armazenamento e compartilhamento
- README.txt — instruções
